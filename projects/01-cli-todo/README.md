# Project 1: Command-Line TODO Tool

## Goal

Build a small CLI app:

```text
todo add "learn pattern matching"
todo list
todo done 1
todo remove 1
```

## Focus Areas

- Mix project structure
- Pattern matching
- Lists, maps, and structs
- File I/O
- Basic CLI design
- ExUnit tests

## Suggested Versions

1. In-memory pure data structure, exercised via IEx (no CLI yet) — focus on the core list functions
2. Add the CLI shell and file persistence together — neither makes sense without the other
3. Add tests and improve parsing and error handling

## Completion Criteria

- The CLI can add, list, complete, and remove tasks
- Data persists between runs
- Core logic is covered by tests
